# الحق الكود — شاشة هدايا بالأكواد

شاشة عرض للمحل: أكواد QR تتحرك على الشاشة وتتجمع على شكل قلب، والزبون يمسح أي كود بجواله فتظهر هديته على جواله وعلى الشاشة الكبيرة ("يا سلااام... الهدية لك!").

## التشغيل
1. ارفع `index.html` على أي استضافة (مثل GitHub Pages).
2. افتح الرابط على شاشة المحل واضغط **ملء الشاشة**.
3. من **الإعدادات** غيّر اسم المتجر والهدايا والكميات (سطر لكل هدية: `الاسم | الأيقونة | الكمية`).

- الربط بين الجوال والشاشة يتم عبر خادم ntfy المجاني (`https://ntfy.sh`) ولا يحتاج حساب أو سيرفر خاص.
- كل كود يُستخدم مرة واحدة؛ الشاشة تتحقق منه ثم تستبدله بكود جديد وتنقص العداد.
- قائمة آخر الفائزين في الإعدادات للتحقق عند الكاشير.
- اضغط أي كود على الشاشة نفسها لتجربة الفوز.
- عدّل `CONFIG` أعلى السكربت قبل الرفع حتى تطابق أسماء الهدايا على الجوال لو الشاشة غير متصلة.
- `content.html` نفس الصفحة بدون الهيكل الخارجي (للمعاينة).
